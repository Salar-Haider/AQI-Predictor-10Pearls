# Islamabad AQI Predictor

An end-to-end serverless AQI prediction system for Islamabad.

## Technologies

- Python
- Open-Meteo
- Hopsworks
- Scikit-learn
- XGBoost
- SHAP
- GitHub Actions
- Streamlit

## Project Goal

The system collects weather and air-quality data, creates features, trains AQI prediction models, and provides a 3-day AQI forecast through an interactive dashboard.
